# 他社の動画から学んだこと (2026-10-24)

方法: 各サイトのトップの公開動画を、`tools/study/` の決定論のスクリプトで測り(動きの速さ → 抽出間隔 → 全フレームで場面転換・動きの長さ・音)、
そのうえで概観と密な区間を目視した。**数字と型だけ**を記録する。台本・文言・人物・固有の構図は書き写さない。元の動画とフレームは非公開(このリポジトリに入れない)。

対象(深掘り): zypsy(リール80秒+ヒーロー7秒)、Landor(ショーリール80秒+ヒーロー10秒)、thebranx(事例3本 約8秒)、Wolff Olins(トップのループ3本 5〜16秒)。
取得できなかった・動画なし: koto(埋め込みが制限されていて取得不可・回避せず)、CGH / Experimental Jetset / A2-SW-HK / Lippincott(動画なし)。
**第2回(2026-10-25 深夜)**: Saffron(トップのリール5本 6〜6.6秒)、Collins(トップのヒーロー 30秒・公開HLS)、FutureBrand(ショーリール80秒+ロゴのループ10秒)、DesignStudio(トップのヒーロー 84秒・webm)を追加。Pentagram は動画ファイルなし(カードは GIF を imgix が変換したもの)で対象外。合計9本・約2,490コマ。第1回と合わせて8サイト・19本。
注: 第1回の記録は「Collins: 動画なし」「FutureBrand: 調査不能」だった。前者は取得先の取り違え(`collins.co` は別の会社。ブランドエージェンシーは `wearecollins.com`)、後者はブラウザの接続エラーで、サイトの問題ではなかった。

## 2件以上の動画で見えた技法(エンジンに入れたもの)
| 技法 | 見えた場所 | エンジンの型 |
|---|---|---|
| **常駐レイヤー**: 装飾・ラベル・物体は動かさず、背景の内容だけが入れ替わる | thebranx(装飾)、Wolff Olins(文字ラベル・3D物体)、zypsy(チップ) | `layers` |
| **フリッカーのバースト**: 0.1〜0.2秒ごとの hard cut を約1.4秒、そのあと長い静止 | Wolff Olins、thebranx(約0.2秒の入れ替え)、Landor(高速モンタージュ) | `flicker` |
| **遷移を図形で作る**: 縦帯のワイプ、形のワイプ、縦のロール(押し出し) | zypsy、Landor、thebranx | `wipeBars`、`slide`(押し出しは2つの slide) |
| **拡大抜け**: 文字が0.17〜0.2秒で10倍近くまで拡大し、次の場面へ | zypsy(+色反転のマッチカット) | `zoomThrough` |
| **形から始まるロゴ**: 形が現れて回り、ワードマークが伸びる | thebranx、zypsy、Landor(終わりのカード) | `logoReveal` |
| **ブランド色で挟む**: 冒頭と末尾を同じ全面色にする | Landor、zypsy | 見本 `brand-reel` の構成(型ではなく作法) |
| **数字と棒を同期**: 同じイージング・同じ時間で動かす | Landor、zypsy | `counter` の `ease:'cubic'` + `keys` |
| **1字ずつ打ち込む**: 文字を1字ずつ出し、キャレットを後ろに付ける。ワードマークは約0.17秒/字(約6字/秒)、検索欄は約0.1〜0.13秒/字(約8〜10字/秒)。打ち終えたら hard cut | Collins(ロゴ文字)、Saffron(検索欄の入力) | `typeOn`(第2回で追加。`cps` で速さ、`caret` で棒) |

第2回で**既存の型の裏付け**も増えた: 常駐レイヤー(Saffron: 同じ社標を固定して背景の絵だけ入れ替わる)、拡大抜け(Saffron: 社標の形が拡大して次の場面へ)、形から始まるロゴ(Collins: 点の輪 → 記号、Saffron: `&` から広がって3文字に)。

## 型にはしないが、数字で言えること(エンジンの既存の型で表せる)
- **全面の色カードを句読点にする**: 写真・映像の連続のあいだに、ブランド色の全面カード(中央にロゴ)を挟む。測定(10fps・48×27、同じ色が55%以上の飽和色を「カード」)で、**Collins 21%(6回・中央値1.2秒)、Landor 24%(13回・0.6秒)、zypsy 12%(7回・1.1秒)、FutureBrand 7%(11回・0.4秒)**。毎分5〜12回、1回0.4〜1.2秒。`scenes` の `bg` とロゴ要素でそのまま書ける。

## 第2回で測った・確認したこと
- Collins は冒頭の約6秒を暗い1カットで置き、そこから約0.4秒のカットに切り替える(静 → 速の落差)。FutureBrand は冒頭約2.7秒と末尾が暗い画面。第1回の Wolff Olins(バーストと静止)と同じ「落差で見せる」型。
- DesignStudio のヒーローは唯一の例外: ディゾルブ約0.6秒でつなぐ5カット/分のゆっくりした記録映像。他の7サイトはほぼ hard cut。**ディゾルブが基調なのは古い素材だけだった**(1件なので型にはしない)。
- Saffron の6秒リールは「1本=1案件・約6秒でループ」の単位で、1本の中に型を1〜2個しか使わない(例: 数字のカウント、文字行の積み重ね、社標の拡大)。詰め込まない。

## 測ったが、採用しなかったこと
- **カットを拍の格子に合わせる**: 仮説(「効果音やカットを拍に揃える」)を測った(`tools/study/audio-sync.mjs`)。
  音のアタックへの一致は偶然の約1.4倍(zypsy 29% vs 偶然20%、Landor 33% vs 24%)。拍の周期に対する位相のそろい具合は R=0.19(p=0.28)と R=0.06(p=0.81)で、**偶然と区別できない**。
  → エンジンには入れない。限界: 簡易のテンポ推定で、曲の途中でテンポが変わる/フレーズ単位で合わせている場合は検出できない。判断を変えるなら、より良い拍の検出で測り直す。
- 「文字を巨大にする」など、1件でしか見えなかったものは、型にせず記録だけにした(下の「候補」)。

## 候補(1件で観察。2件目が出たら型にする)
- 縦帯のワイプの前後に、色反転(黒↔白)のカットを置く(zypsy)。
- 文字を画面高の約1/4の行高で置く、行間を詰める(zypsy)。
- 画面比率 2.44:1(シネマスコープ)の事例ダイジェスト(thebranx)。
- 3Dの金属質の物体が、背景の実写の入れ替わりをまたいで残る(Wolff Olins)。Figma に3Dは無く、近似になる。
- 新しい絵が前の絵を消さずに**上に積み重なる**コラージュ(約0.2秒おきに5〜6枚、Saffron の1本)。
- 同じ文字行を**縦に繰り返して積む**(Saffron の1本)。
- カットのあいだで写真が**ゆっくり拡大する**押し込み(Collins・Saffron で目視。拡大率は未測定。測れたら2件目として型にする)。
- 冒頭と末尾を暗い画面にして自社名で閉じる(FutureBrand の1本。Landor・zypsy の「ブランド色で挟む」と同じ作法の暗色版)。

## 自分の作品に当てた結果
- ペース検査(`engine/core/pacing.mjs`)を2本の既存見本に当てたところ、**動きの中央値が0.85〜0.9秒で、参考の0.17〜0.6秒より遅い**と出た。意図的に落ち着いた説明動画だったので値は変えていないが、新しい型の既定値は 0.55秒(`enterTiltBlur`)・0.45秒(`fadeUp`)に変えた。
- 第2回: 新しい型 `typeOn` を見本 `examples/type-on`(4秒)で確認した。HTML(スナップ8点で期待どおりに1字ずつ出る)と Figma(33ノード・29トラック・4秒のタイムライン、`export_video` のコマで同じ打ち込み)の両方で動いた。コントラスト検査は全4見本とも0件。**変えていない3見本(kurumi・podcast-teaser・brand-reel)は、変更前(HEAD)と変更後のコンパイル結果が完全に一致**した(型を足しただけで既存の経路には触れていないため、画像比較より強い確認)。
- 見本 `brand-reel` で、上の7つを使った。ペース検査は警告なし(場面長の中央値2.0秒、動きの中央値0.4秒)。

## 測定ツール(`tools/study/`)の教訓
- 間隔は「動きの最短の長さ」で決める(0.3秒未満なら原fps、通常 0.1秒、全部が1秒以上なら 0.2秒)。**ただしカットが密なとき(場面長 0.6秒未満)は 0.1秒に戻す**。Wolff Olins のカルーセルで、動きの長さだけで見て 0.2秒にしてしまう誤りに気づいて直した。
- 目視の前に測る。2秒おきの間引きは約5%しか見ていない。
