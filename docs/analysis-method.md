# 参考動画の「技法の分析」

目的は、動画の**作り方**を測ること。映像・台本・人物・ロゴは使わない。

## やってよいこと
- 視聴して、構成・カットの長さ・字幕の出し方・動きの型・色・書体の組み合わせを記録する。
- 手元のフレーム（自分で撮ったスクリーンショットなど）から、タイミングとイージングを測る。
- そこから**自分の題材・自分の素材**で、同じ型の動きを作る。

## やらないこと
- 動画ファイルを保存・再配布する、配信ストリームを抜き出す。
- 映像・台本・人物・ロゴの複製、または「少し変えただけ」の再現。
- 抽出したフレームを公開リポジトリに入れる（第三者の映像）。

## 測り方
1. **全フレームで見る**: 0.1秒刻みなら全部。2秒おきの間引きは約5%しか見ていない（過去にこの失敗をした）。
2. **カット検出**（決定論）:
   ```bash
   ffmpeg -framerate 10 -i frames/%04d.png -vf "scale=480:-1,select='gt(scene,0.18)',showinfo" -f null - 2>&1 | grep -o "pts_time:[0-9.]*"
   ```
   0.1秒ずつ3連続で出る箇所は 0.2〜0.3 秒のトランジション。
3. **動きの細部**: 気になる区間を 0.1 秒刻みで 30 コマ並べる（`ffmpeg ... -vf "scale=400:-1,tile=6x5"`）。入りの傾き・ぼけ・時間差・イージングの緩急を読む。
4. **記録するもの**: 場面数、場面長の中央値と最短・最長、動きの型（ずらし幅・継続時間・イージング）、色数、書体の組み合わせ。
5. 記録は**数字と型**で書く。台本や画面内の文言は書き写さない。
